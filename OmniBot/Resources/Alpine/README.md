# Alpine root filesystem

`alpine-minirootfs-3.21.0-aarch64.tar.gz` is the official Alpine Linux 3.21.0
AArch64 minirootfs used by the embedded iSH ARM64 runtime.

- Source: https://dl-cdn.alpinelinux.org/alpine/v3.21/releases/aarch64/alpine-minirootfs-3.21.0-aarch64.tar.gz
- SHA-256: `f31202c4070c4ef7de9e157e1bd01cb4da3a2150035d74ea5372c5e86f1efac1`

The archive is expanded into the app's Application Support directory on first
launch and then persists across launches. See Alpine's package metadata for the
licenses of the packages contained in the root filesystem.
